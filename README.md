# TFM - Machine Learning para la clasificación de diabetes

Proyecto desarrollado como parte del Trabajo de Fin de Máster (TFM) del Máster en Inteligencia Artificial aplicada a la salud.

## Objetivo

Desarrollar y evaluar modelos de aprendizaje automático para la clasificación de diabetes utilizando el Pima Indians Diabetes Database.

El proyecto estudiará especialmente el impacto del tratamiento de los valores ausentes implícitos y del modelo de aprendizaje automático seleccionado sobre el rendimiento predictivo.

## Dataset

El proyecto utiliza el archivo `diabetes.csv`, correspondiente al Pima Indians Diabetes Database.

El conjunto de datos contiene 768 registros y las siguientes variables:

- `Pregnancies`: número de embarazos.
- `Glucose`: concentración de glucosa.
- `BloodPressure`: presión arterial diastólica.
- `SkinThickness`: grosor del pliegue cutáneo.
- `Insulin`: insulina sérica.
- `BMI`: índice de masa corporal.
- `DiabetesPedigreeFunction`: función de pedigree de diabetes.
- `Age`: edad.
- `Outcome`: variable objetivo.

## Metodología

El proyecto incluirá:

1. Análisis exploratorio de los datos.
2. Identificación y tratamiento de valores ausentes implícitos.
3. Preprocesamiento de las variables.
4. Entrenamiento de modelos de clasificación.
5. Validación mediante validación cruzada estratificada.
6. Evaluación mediante diferentes métricas de rendimiento.
7. Análisis de los umbrales de clasificación.
8. Análisis de la importancia de las variables.
9. Discusión de resultados y limitaciones.

## Modelos

Se evaluarán diferentes algoritmos de aprendizaje automático, entre ellos:

- Regresión logística.
- Support Vector Machine (SVM).
- Random Forest.
- Gradient Boosting.
